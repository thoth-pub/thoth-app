# Zitadel-Organisations-ID

Dieser Bereich verwaltet die **Zitadel-Organisations-ID**.

*Hinweis: Dies ist ein Konfigurationsfeld und sollte nur geändert werden, wenn Sie mit der Einrichtung von Benutzerkonten vertraut sind.*

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **Zitadel-Organisations-ID**: Texteingabe für die eindeutige Kennung der Organisation in Zitadel, die mit diesem Verlag verknüpft ist. Sie dient dazu, Benutzerinnen und Benutzer sowie ihre Zugriffsberechtigungen dem richtigen Verlag zuzuordnen.
