# Auszeichnungstitel

Dieser Bereich verwaltet den **Auszeichnungstitel** einer dem Werk verliehenen Auszeichnung. Abonnentinnen und Abonnenten von [Thoth Pyramid](https://thoth.pub/) können diese zusätzlichen Metadaten als Teil ihrer Buchseiten anzeigen.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **Auszeichnungstitel**: Texteingabe für den Titel der Auszeichnung.
