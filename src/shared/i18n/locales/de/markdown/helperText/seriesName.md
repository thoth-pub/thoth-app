# Name

Dieser Bereich verwaltet den **Namen** einer Reihe. Eine Reihe ist eine offene Folge von Bänden, die in der Regel eines oder mehrere gemeinsame Merkmale aufweisen, wie etwa Thema, Gestaltung oder Autorengemeinschaft.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **Name**: Texteingabe für den Namen der Reihe.
