# Rezensionstitel

Dieser Bereich verwaltet den **Rezensionstitel** einer Rezension des Werks. Abonnentinnen und Abonnenten von [Thoth Pyramid](https://thoth.pub/) können Rezensionen als Teil ihrer Buchseiten anzeigen.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **Rezensionstitel**: Texteingabe für den Titel der Rezension.

## JATS XML

Der **Rezensionstitel** unterstützt die JATS-XML-Formatierung für Fettschrift, Kursivschrift, Durchgestrichen und Unterstrichen.

- [Fettschrift](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/bold.html): `<bold>Text</bold>`
- [Kursivschrift](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/italic.html): `<italic>Text</italic>`
- [Durchgestrichen](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/strike.html): `<strike>Text</strike>`
- [Unterstrichen](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/underline.html): `<underline>Text</underline>`
