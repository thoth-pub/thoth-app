# Cover-URL

Dieser Bereich verwaltet die **Cover-URL**. Abonnentinnen und Abonnenten von [Thoth Obelisk](https://thoth.pub/) können ihre Coverdatei direkt hochladen.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **Cover-URL**: Texteingabe für die URL des Covers des Werks. Dies ist in der Regel eine JPG- oder PNG-Datei.
