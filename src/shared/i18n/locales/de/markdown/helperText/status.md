# Status

Der **Status**-Chip zeigt den aktuellen Status des Werks an.

- **Angekündigt**: Das Werk befindet sich in Bearbeitung und soll veröffentlicht werden. Dies ist der typische Status für ein Werk, das noch nicht erschienen ist, aber für die Veröffentlichung geplant ist.
- **Aktiv**: Das Werk ist veröffentlicht und derzeit verfügbar. Dieser Status zeigt an, dass das Werk offiziell erschienen ist.
- **Zurückgezogen**: Das Werk wurde aus dem Publikationsprozess zurückgezogen und wird aus allen Vertriebskanälen entfernt. Dieser Status zeigt an, dass das Werk nicht mehr zum Kauf oder zur Verbreitung verfügbar und nicht mehr zugänglich ist.
- **Ersetzt**: Das Werk wurde durch eine neue Ausgabe abgelöst; die vorige Ausgabe gilt nunmehr als veraltet.
- **Auf unbestimmte Zeit verschoben**: Die Veröffentlichung des Werks wurde auf unbestimmte Zeit verzögert. Sie kann zu einem späteren Zeitpunkt wieder aufgenommen werden, derzeit ist jedoch kein Veröffentlichungsdatum festgelegt.
- **Abgesagt**: Das Werk wurde dauerhaft abgesagt und wird nicht veröffentlicht.

Sobald der Status eines Werks in Thoth auf **Aktiv** gesetzt wurde, gilt es als veröffentlicht. Für Abonnentinnen und Abonnenten von [Thoth Obelisk](https://thoth.pub/), [Sphinx](https://thoth.pub/) und [Pyramid](https://thoth.pub/) werden nach der Veröffentlichung eines Werks alle Metadatenänderungen automatisch als Teil von Thoths [DOI-Registrierungsdienst](https://thoth.pub/) an Crossref weitergegeben. Aus diesem Grund setzt Thoth das oben dargestellte Statusablaufdiagramm durch; veröffentlichte Werke können anschließend weder depubliziert noch gelöscht werden. Werke sollten erst dann auf **Aktiv** gesetzt werden, wenn sie offiziell erschienen und für die Verbreitung auf anderen Plattformen bereit sind.

Wie im Ablaufdiagramm dargestellt, können veröffentlichte (d. h. aktive) Werke in Thoth nur auf **Zurückgezogen** oder **Ersetzt** gesetzt werden. Sie können nicht auf **Auf unbestimmte Zeit verschoben** oder **Abgesagt** gesetzt werden.
