# Bezugsquellen

Dieser Bereich verwaltet die **Bezugsquellen** einer Publikation. Dabei kann es sich beispielsweise um Websites von Online-Shops oder Vertriebspartnern (für Druckbücher) oder Repositorien (für digitale Bücher) handeln.

Im Bearbeitungsmodus können die folgenden Felder bearbeitet werden:

- **Plattform**: Auswahl einer Plattform aus dem Dropdown-Menü. Dazu gehören alle Plattformen, an die Thoth Metadaten weitergibt, sowie folgende Plattformen:
  - **Verlagswebsite**: Die Website des Verlags, sofern dieser die Publikation selbst auf einem eigenen Server hostet.
  - **Thoth (Verlags-CDN)**: Das von Thoth unter der Domain des Verlags betriebene Content-Delivery-Network, verfügbar für Abonnentinnen und Abonnenten von [Thoth Obelisk](https://thoth.pub/), [Sphinx](https://thoth.pub/) und [Pyramid](https://thoth.pub/).
  - **Sonstige**: Jede andere nicht aufgeführte Plattform.
- **Zielseiten-URL**: die URL der Zielseite der Publikation. Diese Webseite stellt in der Regel eine menschenlesbare Präsentation der Publikation dar, etwa die Produktseite bei Amazon oder ein JSTOR-Eintrag.
- **Volltext-URL**: die URL zum Volltext der Publikation. Dabei handelt es sich um eine URL, die direkt zur digitalen Buchdatei auf der angegebenen Plattform führt. Diese URL ist in der Regel nur auf offenen Plattformen verfügbar. Dieses Feld ist ausschließlich für digitale Publikationen verfügbar. Alternativ können Abonnentinnen und Abonnenten von [Thoth Obelisk](https://thoth.pub/), [Sphinx](https://thoth.pub/) oder [Pyramid](https://thoth.pub/) auf das Anhang-Symbol klicken, um ihre Datei direkt in ihr CDN hochzuladen.
- **Kanonisch**: Kennzeichnet die maßgebliche Version der Publikation. Bei digitalen Publikationen ist dies standardmäßig der Speicherort **Thoth (Verlags-CDN)**, sofern verfügbar.
