# Interne ID

Die **Interne ID** zeigt die verlagsinterne Referenz für das Werk an. Dabei handelt es sich häufig um eine Kurztitelform, eine Nummer oder einen Code. Die Interne ID ermöglicht eine schnelle Identifizierung eines Werks. Es wird empfohlen, dass jeder Verlag ein internes Referenzsystem für seine Werke entwickelt.
