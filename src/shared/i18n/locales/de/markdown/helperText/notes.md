# Anmerkungen

Dieser Bereich verwaltet die **Allgemeine Anmerkung** und die **Bibliografieanmerkung** zum Werk. Diese Felder werden in Metadatensätzen in der Regel nicht mehr verwendet, mit Ausnahme von MARC-Datensätzen.

Im Bearbeitungsmodus können die folgenden Felder bearbeitet werden:

- **Allgemeine Anmerkung**: Texteingabe für ein allgemeines Feld zur Aufnahme von Informationen, für die kein spezifisches Feld vorgesehen ist. Beispiele für allgemeine Anmerkungen: „Frühere Ausgabe: 2017"; „Links zu weiteren Ressourcen sind auf der Website des Verlags verfügbar"; „Bitte beachten Sie, dass die mathematischen Formeln in diesem Buch in MathML kodiert sind."
- **Bibliografieanmerkung**: Texteingabe für eine Anmerkung, die darauf hinweist, dass das Werk eine Bibliografie oder ähnliche Informationen enthält. Beispiele für Bibliografieanmerkungen: „Enthält Bibliografie (Seiten 289–321) und Register"; „Enthält bibliografische Nachweise."
