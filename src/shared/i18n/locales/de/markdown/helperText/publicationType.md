# Publikationstyp

Dieser Bereich verwaltet den **Publikationstyp** einer Publikation. Publikationen sind eigenständige Instanzen eines einzelnen Werks eines bestimmten Materialtyps.

Im Bearbeitungsmodus kann der **Publikationstyp** aus dem Dropdown-Menü ausgewählt werden. Folgende Optionen stehen zur Verfügung:

- **AZW3**: digitales Buch im AZW3-Format. AZW3 ist ein proprietäres Amazon-Kindle-E-Book-Dateiformat, das eine Teilmenge von HTML- und CSS-Funktionen unterstützt und als Container für eine MOBI-Datei fungiert. Unterstützung und Weiterentwicklung von AZW3 wurden eingestellt.
- **DOCX**: digitales Buch im DOCX-Format. DOCX ist ein komprimiertes, XML-basiertes Dateiformat, das von Microsoft für die Darstellung von Textverarbeitungsdokumenten entwickelt wurde.
- **EPUB**: digitales Buch im EPUB-Format. EPUB ist ein komprimiertes, XML-basiertes E-Book-Dateiformat, das vom International Digital Publishing Forum veröffentlicht wurde und von einer Vielzahl von E-Readern unterstützt wird.
- **FictionBook**: digitales Buch im FictionBook-Format. FictionBook ist ein offenes XML-basiertes E-Book-Format.
- **Hardcover**: gedrucktes Buch mit festem Einband.
- **HTML**: digitales Buch im HTML-Format. Hypertext Markup Language (HTML) ist die Standard-Auszeichnungssprache für menschenlesbare Dokumente, die in einem Webbrowser angezeigt werden sollen.
- **MOBI**: digitales Buch im MOBI-Format. MOBI ist ein von Mobipocket entwickeltes E-Book-Dateiformat, das später von Amazon als Grundlage für AZW3 verwendet wurde. Unterstützung und Weiterentwicklung von MOBI wurden eingestellt.
- **MP3**: Hörbuch im MP3-Format. MPEG-1/MPEG-2 Audio Layer III (MP3) ist ein offenes, verlustbehaftetes Audiokodierformat, das hauptsächlich von der Fraunhofer-Gesellschaft in Deutschland entwickelt wurde.
- **Taschenbuch**: gedrucktes Buch mit flexiblem Einband.
- **PDF**: digitales Buch im PDF-Format. PDF ist ein menschenlesbares Dateiformat, das von Adobe entwickelt wurde. Es basiert auf PostScript und kodiert das Erscheinungsbild von Informationen auf einer gedruckten Seite.
- **WAV**: Hörbuch im WAV-Format. Waveform Audio File Format (WAV) ist ein von IBM und Microsoft entwickeltes Audiodateiformat.
- **XML**: digitales Buch im XML-Format. Extensible Markup Language (XML) ist eine Auszeichnungssprache, die sowohl für menschenlesbare als auch für maschinenlesbare Dokumente konzipiert ist.
