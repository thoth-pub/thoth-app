# Sprachen

Dieser Bereich verwaltet die im Werk verwendeten **Sprache(n)**.

Im Bearbeitungsmodus können die folgenden Felder bearbeitet werden:

- **Sprache**: Auswahl der im Werk verwendeten Sprache. Die Liste der zulässigen Sprachen folgt [ISO 639-3](https://iso639-3.sil.org/code_tables/639/data). Es wird empfohlen, mindestens eine Sprache anzugeben.
- **Sprachbeziehung**: Auswahl der Beziehung der gewählten Sprache zum Werk. Folgende Optionen stehen zur Verfügung:
  - Original;
  - Übersetzt aus;
  - Übersetzt in.
