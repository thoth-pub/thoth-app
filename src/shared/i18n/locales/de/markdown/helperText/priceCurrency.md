# Preis

Dieser Bereich verwaltet den **Preis** einer Publikation.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **Preis**: Eingabe des Preises als Dezimalzahl (mit zwei Nachkommastellen) sowie Auswahl der Währung aus dem Dropdown-Menü gemäß dem [ISO 4217](https://en.wikipedia.org/wiki/ISO_4217)-Standard für Bezeichnungen und Abkürzungen.

Weitere Preise in anderen Währungen können durch Klicken auf **Neuen Preis hinzufügen** eingegeben werden.
