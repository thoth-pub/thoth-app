# LCCN

Dieser Bereich verwaltet die [Library of Congress Control Number](https://www.loc.gov/programs/preassigned-control-number/about-this-program/) (**LCCN**). Dieser persistente Identifikator ist ausschließlich für Verlage mit Sitz in den USA relevant.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **LCCN**: Texteingabe für die LCCN des Werks.
