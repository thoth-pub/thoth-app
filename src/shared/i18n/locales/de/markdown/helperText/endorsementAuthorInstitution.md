# Autoreninstitution

Dieser Bereich verwaltet die **Autoreninstitution** einer dem Werk zugehörigen Empfehlung.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **Autoreninstitution**: Suche nach der Institution der Verfasserin oder des Verfassers der Empfehlung in der [ROR](https://ror.org/)-Datenbank. Wenn die Institution nicht verfügbar ist, kann bei ROR eine [Aufnahme beantragt](https://docs.google.com/forms/d/e/1FAIpQLSdJYaMTCwS7muuTa-B_CnAtCSkKzt19lkirAKG4u7umH9Nosg/viewform) werden.
