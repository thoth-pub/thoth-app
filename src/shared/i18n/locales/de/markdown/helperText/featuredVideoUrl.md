# Video-URL

Dieser Bereich verwaltet die **Video-URL** eines empfohlenen Videos zum Werk.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **Video-URL**: Texteingabe für die URL des Videos. Alternativ können Abonnentinnen und Abonnenten von [Thoth Pyramid](https://thoth.pub/) auf das Anhang-Symbol klicken, um ihre Datei direkt in ihr CDN hochzuladen.
