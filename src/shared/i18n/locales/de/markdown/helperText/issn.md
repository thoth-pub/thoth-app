# ISSN

Dieser Bereich verwaltet die **ISSN** einer Reihe. Eine ISSN ist ein achtstelliger Code zur Identifizierung fortlaufender Ressourcen. Eine fortlaufende Ressource ist eine Ressource, die auf einem beliebigen Medium zeitlich unbegrenzt erscheint.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **ISSN**: Texteingabe für die [ISSN](https://portal.issn.org/) der Reihe.
