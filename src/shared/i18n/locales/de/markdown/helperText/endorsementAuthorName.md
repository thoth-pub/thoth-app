# Autorenname

Dieser Bereich verwaltet den **Autorennamen** einer dem Werk zugehörigen Empfehlung. Abonnentinnen und Abonnenten von [Thoth Pyramid](https://thoth.pub/) können Empfehlungen als Teil ihrer Buchseiten anzeigen.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **Autorenname**: Texteingabe für den Namen der Verfasserin oder des Verfassers der Empfehlung.
