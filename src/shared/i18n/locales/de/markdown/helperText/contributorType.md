# Beitragstyp

Dieser Bereich verwaltet den **Beitragstyp** einer mitwirkenden Person.

Im Bearbeitungsmodus kann der **Beitragstyp** aus dem Dropdown-Menü ausgewählt werden. Folgende Optionen stehen zur Verfügung:

- Nachwort von
- Autor/Autorin
- Beiträge von
- Herausgeber/in
- Vorwort von
- Illustrator/in
- Indexersteller/in
- Einleitung von
- Musikredakteur/in
- Fotograf/in
- Vorrede von
- Forschung von
- Software von
- Übersetzer/in

Um Hauptbeitragende zu kennzeichnen, aktivieren Sie das Kontrollkästchen **Hauptbeitrag**.
