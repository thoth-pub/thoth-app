# URL

Dieser Bereich verwaltet die **URL** einer im Werk enthaltenen Referenz.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **URL**: Texteingabe für die URL, die auf die Referenz verweist. Dies kann die URL der Referenz selbst sein (z. B. eine gehostete PDF-Datei) oder die Zielseite der Referenz auf der Website des Verlags bzw. auf der Website eines Repositoriums wie JSTOR oder Project MUSE. Hierbei darf es sich nicht um einen DOI handeln.
