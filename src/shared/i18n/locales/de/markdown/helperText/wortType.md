# Werktyp

Dieser Bereich verwaltet den **Werktyp** (Pflichtfeld). Der **Werktyp** wird bereits während des Einrichtungsprozesses festgelegt.

Folgende Werktypen stehen zur Verfügung:

- **Sammelband**: eine Sammlung kürzerer Werke verschiedener Autorinnen und Autoren zu einem übergeordneten Thema.
- **Zeitschriftenheft**: eine einzelne Ausgabe innerhalb einer Reihe von Sammlungen verwandter Artikel.
- **Monografie**: ein längeres Werk zu einem einzelnen Thema von einer kleinen Anzahl von Autorinnen und Autoren.
- **Lehrbuch**: ein Werk, das für Bildungszwecke eingesetzt wird.
