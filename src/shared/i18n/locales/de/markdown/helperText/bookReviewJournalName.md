# Zeitschriftenname

Dieser Bereich verwaltet den **Zeitschriftennamen** einer Rezension des Werks.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **Zeitschriftenname**: Texteingabe für den Namen der Zeitschrift oder eines anderen Publikationsorgans, in dem die Rezension veröffentlicht wurde.
