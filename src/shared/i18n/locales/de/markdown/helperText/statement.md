# Erklärung

Dieser Bereich verwaltet die **Barrierefreiheitserklärung** des Verlags.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **Erklärung**: Texteingabe für die [Barrierefreiheitserklärung](https://compass.copim.pub/books/09-open-book-accessibility/page/communicating-with-everyone-accessibility-statements) des Verlags oder eine URL zur Erklärung auf der Website des Verlags.
