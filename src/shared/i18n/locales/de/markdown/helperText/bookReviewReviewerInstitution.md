# Rezensenteninstitution

Dieser Bereich verwaltet die **Rezensenteninstitution** einer Rezension des Werks.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **Rezensenteninstitution**: Suche nach der Institution der Verfasserin oder des Verfassers der Rezension in der [ROR](https://ror.org/)-Datenbank. Wenn die Institution nicht verfügbar ist, kann bei ROR eine [Aufnahme beantragt](https://docs.google.com/forms/d/e/1FAIpQLSdJYaMTCwS7muuTa-B_CnAtCSkKzt19lkirAKG4u7umH9Nosg/viewform) werden.
