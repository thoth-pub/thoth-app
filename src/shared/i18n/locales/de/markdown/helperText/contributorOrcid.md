# ORCID

Dieser Bereich verwaltet die **ORCID** einer mitwirkenden Person.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **ORCID**: Texteingabe für die [ORCID](https://orcid.org/) der mitwirkenden Person. Es wird empfohlen, dass mitwirkende Personen eine ORCID anlegen, sofern sie noch keine besitzen, da dies die eindeutige Identifizierung in der gesamten Buchpublikationskette ermöglicht.
