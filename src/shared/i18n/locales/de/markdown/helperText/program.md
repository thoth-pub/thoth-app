# Förderprogramm

Dieser Bereich verwaltet das **Förderprogramm**, im Rahmen dessen das Werk finanziert wurde.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **Förderprogramm**: Texteingabe für den Namen des Förderprogramms. Dies ist das übergeordnete Programm, im Rahmen dessen der Projektförderbeitrag gewährt wird.
