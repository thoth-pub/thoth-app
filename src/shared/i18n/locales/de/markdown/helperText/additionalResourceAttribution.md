# Quellenangabe

Dieser Bereich verwaltet die **Quellenangabe** einer zusätzlichen Ressource zum Werk.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **Quellenangabe**: Texteingabe für die Quellenangabe der zusätzlichen Ressource. Dies kann der Name der Website, der Plattform, der Autorin oder des Autors usw. sein.
