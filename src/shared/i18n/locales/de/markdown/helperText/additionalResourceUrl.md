# Ressourcen-URL

Dieser Bereich verwaltet die **Ressourcen-URL** einer zusätzlichen Ressource zum Werk.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **Ressourcen-URL**: Texteingabe für die URL, die auf die zusätzliche Ressource verweist. Hierbei darf es sich nicht um einen DOI oder einen Handle handeln.
