# Ressourcentyp

Dieser Bereich verwaltet den **Ressourcentyp** einer zusätzlichen Ressource zum Werk.

Im Bearbeitungsmodus kann aus dem Dropdown-Menü ausgewählt werden. Folgende Typen stehen zur Verfügung:

- Artikel
- Audio
- Blog
- Buch
- Datensatz
- Dokument
- Bild
- Karte
- Sonstiges
- Quelle
- Tabellenkalkulation
- Video
- Website
