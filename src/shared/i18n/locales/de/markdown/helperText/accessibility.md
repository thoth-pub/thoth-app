# Barrierefreiheit

Dieser Bereich verwaltet die **Barrierefreiheit** einer Publikation. Dieser Bereich ist ausschließlich für digitale Publikationen verfügbar, mit Ausnahme von Hörbüchern.

Im Bearbeitungsmodus können die folgenden Felder bearbeitet werden:

- **Spezifikation**: Auswahl der Barrierefreiheitsspezifikation, der die Publikation entspricht:
  - [WCAG 2.1 AA](https://www.w3.org/TR/WCAG21/)
  - [WCAG 2.1 AAA](https://www.w3.org/TR/WCAG21/)
  - [WCAG 2.2 AA](https://www.w3.org/TR/WCAG22/)
  - [WCAG 2.2 AAA](https://www.w3.org/TR/WCAG22/)
  - [PDF/UA-1](https://pdfa.org/resource/iso-14289-pdfua/)
  - [PDF/UA-2](https://pdfa.org/resource/iso-14289-pdfua/)
- **Ausnahme**: Wenn der Verlag in einem bestimmten Rechtsraum von der Pflicht zur Barrierefreiheit seiner Publikationen befreit ist, kann der Ausnahmetyp aus dem Dropdown-Menü ausgewählt werden:
  - Unverhältnismäßige Belastung
  - Grundlegende Änderung des Wesens
  - Kleinstunternehmen
- **Bericht-URL**: URL des Barrierefreiheitsberichts der Publikation.

Weitere umfangreiche Ressourcen zum Thema Barrierefreiheit finden Sie im [Copim Compass](https://compass.copim.pub/books/09-open-book-accessibility).
