## Zusammenfassung

Dieser Bereich verwaltet die **Zusammenfassung** und die **Kurzzusammenfassung**.

Im Bearbeitungsmodus können die folgenden Felder bearbeitet werden:

- **Zusammenfassung**: Texteingabe für die Zusammenfassung des Werks. Wenn ein Werk nur eine Zusammenfassung hat, sollte diese hier eingetragen werden; das Feld für die Kurzzusammenfassung kann leer bleiben.
- **Kurzzusammenfassung**: Texteingabe für die Kurzzusammenfassung. Wird nicht in Metadatenexporten verwendet, kann jedoch für eine verkürzte Zusammenfassung genutzt werden, die beispielsweise in einer Vorschau- oder Ausschnittsansicht auf einer Website angezeigt wird.

## JATS XML

Sowohl **Zusammenfassung** als auch **Kurzzusammenfassung** unterstützen die JATS-XML-Formatierung für Fettschrift, Kursivschrift, Durchgestrichen, Unterstrichen, Absätze, Listen und Hyperlinks.

- [Fettschrift](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/bold.html): `<bold>Text</bold>`
- [Kursivschrift](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/italic.html): `<italic>Text</italic>`
- [Durchgestrichen](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/strike.html): `<strike>Text</strike>`
- [Unterstrichen](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/underline.html): `<underline>Text</underline>`
- [Absätze](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/p.html): `<p>Text</p>`
- [Geordnete Listen](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/list.html): `<ol>Text</ol>`
- [Ungeordnete Listen](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/list.html): `<ul>Text</ul>`
- [Hyperlinks](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/ext-link.html): `<ext-link ext-link-type="uri" xlink:href="#">Text</ext-link>`

## Mehrsprachige Optionen

Das **Sprache**-Dropdown ermöglicht die Festlegung der Sprache für **Zusammenfassung** und **Kurzzusammenfassung**. Die Liste der zulässigen Sprachen und Sprachvarianten umfasst einen zweistelligen [ISO 639-1](https://www.loc.gov/standards/iso639-2/php/code_list.php)-Sprachcode gefolgt von einem zweistelligen [ISO 3166-1 alpha-2](https://en.wikipedia.org/wiki/List_of_ISO_3166_country_codes)-Ländercode.

Die Schaltfläche **Neue Übersetzung hinzufügen** ermöglicht das Hinzufügen einer Übersetzung der **Zusammenfassung** und **Kurzzusammenfassung** in einer anderen Sprache.
