# Ressourcentitel

Dieser Bereich verwaltet den **Ressourcentitel** einer zusätzlichen Ressource zum Werk. Zusätzliche Ressourcen können beliebige ergänzende Multimediamaterialien sein, die nicht direkt marketingbezogen sind, sowie Buchwebsites, Übersetzungen, Datensätze, Audiodateien und Ähnliches.

Zusätzliche Ressourcen können auf Websites angezeigt werden, die einen von Thoth betriebenen Katalog nutzen, wie er über [Thoth Pyramid](https://thoth.pub/) verfügbar ist.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **Ressourcentitel**: Texteingabe für den Titel der zusätzlichen Ressource.
