# Handle

Dieser Bereich verwaltet den **Handle** einer zusätzlichen Ressource zum Werk.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **Handle**: Texteingabe für den [Handle](https://en.wikipedia.org/wiki/Handle_System), der auf die zusätzliche Ressource verweist. Hierbei darf es sich nicht um einen DOI handeln.
