# ISBN

Dieser Bereich verwaltet die **ISBN** einer Publikation.

Im Bearbeitungsmodus kann das folgende Feld bearbeitet werden:

- **ISBN**: Texteingabe für die ISBN-13 der Publikation. ISBN-Nummern können in der Regel über eine [nationale ISBN-Agentur](https://www.isbn-international.org/agencies) bezogen werden. Es wird empfohlen, dass jede Publikation eine eindeutige ISBN erhält.
