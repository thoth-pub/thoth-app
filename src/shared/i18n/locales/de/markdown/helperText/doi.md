# DOI

Dieser Bereich verwaltet den **DOI** (empfohlen) und die **Zielseiten-URL** (empfohlen).

Im Bearbeitungsmodus können die folgenden Felder bearbeitet werden:

- **DOI**: Texteingabe für den Digital Object Identifier (DOI) des Werks (ohne das Präfix `https://doi.org/`). DOIs werden über Registrierungsagenturen wie [Crossref](https://www.crossref.org/) vergeben. Die DOI-Registrierung über Crossref kann mit [Thoth Obelisk](https://thoth.pub/) automatisiert werden.
- **Zielseiten-URL**: Texteingabe für die Zielseiten-URL des Werks. Dies sollte eine gültige URL sein, unter der Nutzerinnen und Nutzer auf das Werk zugreifen können, z. B. die Buchseite auf der Website eines Verlags. Bei dieser URL darf es sich *nicht* um einen DOI handeln.
