# Abmessungen

Dieser Bereich verwaltet die **Abmessungen** einer Publikation. Dieser Bereich ist ausschließlich für Hardcover- und Taschenbuchpublikationen verfügbar.

Im Bearbeitungsmodus können die folgenden Felder bearbeitet werden:

- **Breite**: Dezimalzahleingabe für die **Breite** der Publikation in mm/Zoll.
- **Höhe**: Dezimalzahleingabe für die **Höhe** der Publikation in mm/Zoll.
- **Tiefe**: Dezimalzahleingabe für die **Tiefe** der Publikation in mm/Zoll.
- **Gewicht**: Dezimalzahleingabe für das **Gewicht** der Publikation in g/oz.

Abmessungen können entweder in metrischen oder in imperialen Einheiten eingegeben werden und werden automatisch von einem System in das andere umgerechnet. Die Einheiten können durch Klicken auf das Kettensymbol verknüpft und getrennt werden.
