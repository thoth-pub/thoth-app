## Resumen

Esta sección gestiona el **Resumen** y el **Resumen abreviado**.

El modo de edición permite modificar los siguientes campos:

- **Resumen**: campo de texto para introducir el resumen de la obra. Si la obra tiene un único resumen, debe introducirse aquí y el resumen abreviado puede dejarse en blanco.
- **Resumen abreviado**: campo de texto para introducir el resumen abreviado. No se utiliza en las exportaciones de metadatos, pero puede emplearse para un resumen breve que se muestre, por ejemplo, en una vista de resumen o fragmento en un sitio web.

## XML JATS

Tanto el **Resumen** como el **Resumen abreviado** admiten formato en XML JATS para negrita, cursiva, tachado, subrayado, párrafos, listas e hipervínculos.

- [negrita](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/bold.html): `<bold>texto</bold>`
- [cursiva](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/italic.html): `<italic>texto</italic>`
- [tachado](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/strike.html): `<strike>texto</strike>`
- [subrayado](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/underline.html): `<underline>texto</underline>`
- [párrafos](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/p.html): `<p>texto</p>`
- [listas ordenadas](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/list.html): `<ol>texto</ol>`
- [listas no ordenadas](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/list.html): `<ul>texto</ul>`
- [hipervínculos](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/ext-link.html): `<ext-link ext-link-type="uri" xlink:href="#">texto</ext-link>`

## Opciones multilingües

El menú desplegable **Idioma** permite establecer el idioma del **Resumen** y el **Resumen abreviado**. La lista de idiomas y variantes lingüísticas admitidas combina un código de idioma de dos letras según la norma [ISO 639-1](https://www.loc.gov/standards/iso639-2/php/code_list.php) seguido de un código de país de dos letras según la norma [ISO 3166-1 alpha-2](https://en.wikipedia.org/wiki/List_of_ISO_3166_country_codes).

El botón **Agregar nueva traducción** permite añadir una traducción del **Resumen** y el **Resumen abreviado** en otro idioma.
