# ISSN

Esta sección gestiona el **ISSN** de una serie. Un ISSN es un código de 8 dígitos utilizado para identificar recursos continuados. Un recurso continuado es un recurso, en cualquier soporte, que se publica de forma indefinida a lo largo del tiempo.

El modo de edición permite modificar el siguiente campo:

- **ISSN**: campo de texto para introducir el [ISSN](https://portal.issn.org/) de la serie.
