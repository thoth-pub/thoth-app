# Título del vídeo

Esta sección gestiona el **Título del vídeo** de un Vídeo destacado asociado a la obra. Los suscriptores de [Thoth Pyramid](https://thoth.pub/) pueden mostrar este vídeo personalizado como parte de las páginas de sus libros. Puede tratarse de un vídeo promocional, una entrevista con el autor, etc.

El modo de edición permite modificar el siguiente campo:

- **Título del vídeo**: campo de texto para introducir el título del vídeo.
