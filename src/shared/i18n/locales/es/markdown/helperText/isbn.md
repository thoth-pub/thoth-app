# ISBN

Esta sección gestiona el **ISBN** de una Publicación.

El modo de edición permite modificar el siguiente campo:

- **ISBN**: campo de texto para introducir el ISBN-13 de la publicación. Los números ISBN pueden obtenerse generalmente a través de una [agencia ISBN nacional](https://www.isbn-international.org/agencies). Se recomienda que cada Publicación tenga un ISBN único.
