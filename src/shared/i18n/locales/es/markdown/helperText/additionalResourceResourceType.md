# Tipo de recurso

Esta sección gestiona el **Tipo de recurso** correspondiente a un Recurso adicional relacionado con la obra.

El modo de edición permite seleccionar en el menú desplegable. Los siguientes tipos están disponibles:

- Artículo
- Audio
- Blog
- Libro
- Conjunto de datos
- Documento
- Imagen
- Mapa
- Otro
- Fuente
- Hoja de cálculo
- Vídeo
- Sitio web
