# Nombre completo

Esta sección gestiona el **Nombre completo** de un Colaborador.

Puede crear un nuevo colaborador o buscarlo en la base de datos de Thoth. A efectos de desambiguación, se muestra el [ORCID](https://orcid.org/) del colaborador cuando está disponible. Se recomienda buscar siempre primero el nombre del colaborador, ya que otro usuario de Thoth puede haber creado ya su registro.

El modo de edición permite modificar los siguientes campos:

- **Nombre completo**, desglosado en:
  - **Nombre de pila**: campo de texto para introducir el nombre de pila del colaborador, generalmente el nombre asignado en un acontecimiento significativo de su vida, como el nacimiento, el bautismo, la mayoría de edad o la adquisición de un estatus específico en la sociedad. Los colaboradores pueden optar por abreviar su nombre de pila con una inicial.
  - **Apellido**: campo de texto para introducir el apellido del colaborador, generalmente transmitido por su entorno social, ya sea el padre, la familia (adoptiva), el clan u otro grupo. El apellido se utiliza para ordenar el nombre alfabéticamente.
  - **Nombre completo**: campo de texto para introducir el nombre completo del colaborador, formado por una combinación del **Nombre de pila** y el **Apellido**. El orden puede variar según las preferencias personales o culturales.

*N.B.: modificar cualquiera de los campos anteriores solo cambia el nombre del colaborador para esta obra en concreto. El registro subyacente del colaborador no se modifica, ya que puede estar en uso en otros registros (de otro editor).*
