# Título del premio

Esta sección gestiona el **Título del premio** correspondiente a un Premio recibido por la obra. Los suscriptores de [Thoth Pyramid](https://thoth.pub/) pueden mostrar estos metadatos adicionales como parte de las páginas de sus libros.

El modo de edición permite modificar el siguiente campo:

- **Título del premio**: campo de texto para introducir el título del premio.
