# URL

Esta sección gestiona la **URL** correspondiente a una Referencia contenida en la obra.

El modo de edición permite modificar el siguiente campo:

- **URL**: campo de texto para introducir la URL que enlaza a la Referencia. Puede ser la URL de la propia referencia (como un archivo PDF alojado en línea) o la página de destino de la referencia en el sitio web del editor o en el sitio web de un repositorio como JSTOR o Project MUSE. No puede ser un DOI.
