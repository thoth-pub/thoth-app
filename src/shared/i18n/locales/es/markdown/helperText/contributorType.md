# Tipo de colaborador

Esta sección gestiona el **Tipo de colaborador** de un Colaborador.

El modo de edición permite seleccionar el **Tipo de colaborador** en el menú desplegable. Las siguientes opciones están disponibles:

- Epílogo de
- Autor/a
- Contribuciones de
- Editor/a
- Prólogo de
- Ilustrador/a
- Indizador/a
- Introducción de
- Editor/a musical
- Fotógrafo/a
- Prefacio de
- Investigación de
- Software de
- Traductor/a

Para marcar al colaborador principal, active la casilla **Colaborador principal**.
