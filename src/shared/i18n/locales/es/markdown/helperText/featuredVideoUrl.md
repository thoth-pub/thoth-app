# URL del vídeo

Esta sección gestiona la **URL del vídeo** de un Vídeo destacado asociado a la obra.

El modo de edición permite modificar el siguiente campo:

- **URL del vídeo**: campo de texto para introducir la URL del vídeo. Alternativamente, los suscriptores de [Thoth Pyramid](https://thoth.pub/) pueden hacer clic en el icono de archivo adjunto para subir su archivo directamente a su CDN.
