# ORCID

Esta sección gestiona el **ORCID** de un Colaborador.

El modo de edición permite modificar el siguiente campo:

- **ORCID**: campo de texto para introducir el [ORCID](https://orcid.org/) del colaborador. Se recomienda que los colaboradores creen un ORCID si aún no disponen de uno, ya que esto permite el control de identidad a lo largo de toda la cadena de publicación del libro.
