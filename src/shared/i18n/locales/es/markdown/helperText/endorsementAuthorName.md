# Nombre del autor

Esta sección gestiona el **Nombre del autor** correspondiente a un Aval recibido por la obra. Los suscriptores de [Thoth Pyramid](https://thoth.pub/) pueden mostrar los avales como parte de las páginas de sus libros.

El modo de edición permite modificar el siguiente campo:

- **Nombre del autor**: campo de texto para introducir el nombre del autor del aval.
