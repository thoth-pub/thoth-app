# Declaración

Esta sección gestiona la **Declaración** de accesibilidad del editor.

El modo de edición permite modificar el siguiente campo:

- **Declaración**: campo de texto para introducir la [Declaración de accesibilidad](https://compass.copim.pub/books/09-open-book-accessibility/page/communicating-with-everyone-accessibility-statements) del editor o una URL que apunte a dicha declaración en el sitio web del editor.
