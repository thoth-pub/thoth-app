# ID de organización en Zitadel

Esta sección gestiona el **ID de organización en Zitadel**.

*N.B. Este es un campo de configuración y solo debe modificarse si está familiarizado con la configuración de cuentas de usuario.*

El modo de edición permite modificar el siguiente campo:

- **ID de organización en Zitadel**: campo de texto para introducir el identificador único de la organización en Zitadel vinculada a este editor. Se utiliza para asociar a los usuarios y sus permisos de acceso con el editor correspondiente.
