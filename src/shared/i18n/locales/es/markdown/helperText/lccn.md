# LCCN

Esta sección gestiona el [Número de Control de la Biblioteca del Congreso](https://www.loc.gov/programs/preassigned-control-number/about-this-program/) (**LCCN**). Este identificador persistente solo es relevante para editores con sede en Estados Unidos.

El modo de edición permite modificar el siguiente campo:

- **LCCN**: campo de texto para introducir el LCCN de la obra.
