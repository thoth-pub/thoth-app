# Institución del autor

Esta sección gestiona la **Institución del autor** correspondiente a un Aval recibido por la obra.

El modo de edición permite modificar el siguiente campo:

- **Institución del autor**: búsqueda de la institución del autor del aval en la base de datos [ROR](https://ror.org/). Si la institución no está disponible, [solicite](https://docs.google.com/forms/d/e/1FAIpQLSdJYaMTCwS7muuTa-B_CnAtCSkKzt19lkirAKG4u7umH9Nosg/viewform) a ROR que la añada.
