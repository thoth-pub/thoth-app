# Afiliación

Esta sección gestiona la **Afiliación** de un Colaborador.

- **Institución**: búsqueda de la institución del colaborador en la base de datos [ROR](https://ror.org/). Si la institución no está disponible, [solicite](https://docs.google.com/forms/d/e/1FAIpQLSdJYaMTCwS7muuTa-B_CnAtCSkKzt19lkirAKG4u7umH9Nosg/viewform) a ROR que la añada.
- **Cargo**: campo de texto para introducir el cargo del colaborador en la institución.
