# Título del recurso

Esta sección gestiona el **Título del recurso** correspondiente a un Recurso adicional relacionado con la obra. Los Recursos adicionales pueden ser cualquier material multimedia complementario no directamente relacionado con el marketing, como sitios web del libro, traducciones, conjuntos de datos, archivos de audio, etc.

Los recursos adicionales pueden mostrarse en sitios web que incorporen un catálogo basado en Thoth, disponible a través de [Thoth Pyramid](https://thoth.pub/).

El modo de edición permite modificar el siguiente campo:

- **Título del recurso**: campo de texto para introducir el título del Recurso adicional.
