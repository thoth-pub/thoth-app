# Título do Prémio

Esta secção gere o **Título do Prémio** relativo a um Prémio atribuído à obra. Os subscritores do [Thoth Pyramid](https://thoth.pub/) podem apresentar estes metadados adicionais como parte das páginas dos seus livros.

O modo de edição permite editar o seguinte campo:

- **Título do Prémio**: campo de texto para o título do prémio.
