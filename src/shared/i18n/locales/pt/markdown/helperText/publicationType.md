# Tipo de Publicação

Esta secção gere o **Tipo de Publicação** de uma Publicação. As Publicações são instâncias distintas de uma única obra, de um tipo material específico.

O modo de edição permite selecionar o **Tipo de Publicação** a partir da lista suspensa. Estão disponíveis as seguintes opções:

- **AZW3**: livro digital em formato AZW3. O AZW3 é um formato proprietário de ficheiro de livro eletrónico da Amazon Kindle, que suporta um subconjunto de funcionalidades HTML e CSS, funcionando como um contentor para um ficheiro MOBI. O suporte e desenvolvimento do AZW3 foram descontinuados.
- **DOCX**: livro digital em formato DOCX. O DOCX é um formato de ficheiro baseado em XML e comprimido, desenvolvido pela Microsoft para representar documentos de processamento de texto.
- **EPUB**: livro digital em formato EPUB. O EPUB é um formato de ficheiro de livro eletrónico baseado em XML e comprimido, publicado pelo International Digital Publishing Forum. É suportado por uma variedade de leitores eletrónicos.
- **FictionBook**: livro digital em formato FictionBook. O FictionBook é um formato aberto de livro eletrónico baseado em XML.
- **Capa Dura**: livro impresso com capa dura.
- **HTML**: livro digital em formato HTML. A Linguagem de Marcação de Hipertexto (HTML) é a linguagem de marcação padrão para documentos legíveis por humanos, concebidos para serem apresentados num navegador web.
- **MOBI**: livro digital em formato MOBI. O MOBI é um formato de ficheiro de livro eletrónico desenvolvido pela Mobipocket, mais tarde utilizado pela Amazon como base para o AZW3. O suporte e desenvolvimento do MOBI foram descontinuados.
- **MP3**: audiolivro em formato MP3. O MPEG-1/MPEG-2 Audio Layer III (MP3) é um formato aberto de codificação de áudio com perdas, desenvolvido principalmente pela Fraunhofer Society na Alemanha.
- **Brochura**: livro impresso com capa mole.
- **PDF**: livro digital em formato PDF. O PDF é um formato de ficheiro legível por humanos, desenvolvido pela Adobe. É baseado em PostScript e codifica a apresentação visual da informação numa página impressa.
- **WAV**: audiolivro em formato WAV. O Waveform Audio File Format (WAV) é um formato de ficheiro de áudio desenvolvido pela IBM e pela Microsoft.
- **XML**: livro digital em formato XML. A Linguagem de Marcação Extensível (XML) é uma linguagem de marcação concebida para ser legível tanto por humanos como por máquinas.
