# Título do Recurso

Esta secção gere o **Título do Recurso** relativo a um Recurso Adicional relacionado com a obra. Os Recursos Adicionais podem ser quaisquer materiais multimédia complementares que não estejam diretamente relacionados com marketing, bem como sítios web do livro, traduções, conjuntos de dados, ficheiros de áudio, entre outros.

Os recursos adicionais podem ser apresentados em sítios web com um catálogo alimentado pelo Thoth, disponível através do [Thoth Pyramid](https://thoth.pub/).

O modo de edição permite editar o seguinte campo:

- **Título do Recurso**: campo de texto para o Título do Recurso Adicional.
