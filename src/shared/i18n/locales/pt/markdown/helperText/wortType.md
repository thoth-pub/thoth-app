# Tipo de Obra

Esta secção gere o **Tipo de Obra** (obrigatório). O **Tipo de Obra** já terá sido indicado durante o processo de configuração.

Estão disponíveis os seguintes tipos de obra:

- **Livro Organizado**: uma coleção de obras mais curtas de diferentes autores em torno de um tema comum.
- **Número de Periódico**: uma publicação individual dentro de uma série de coleções de artigos relacionados.
- **Monografia**: uma obra de longo formato sobre um único tema, por um número reduzido de autores.
- **Manual Escolar**: uma obra utilizada para fins educativos.
