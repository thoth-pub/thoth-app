# Título do Vídeo

Esta secção gere o **Título do Vídeo** de um Vídeo em Destaque relativo à obra. Os subscritores do [Thoth Pyramid](https://thoth.pub/) podem apresentar este vídeo personalizado como parte das páginas dos seus livros. Pode tratar-se de um vídeo promocional, de uma entrevista com o autor, entre outros.

O modo de edição permite editar o seguinte campo:

- **Título do Vídeo**: campo de texto para o título do vídeo.
