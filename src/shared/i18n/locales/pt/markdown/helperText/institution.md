# Financiamento

Esta secção gere as fontes de **Financiamento** da Obra. Os financiadores exigem frequentemente que esta informação seja incluída tanto na Obra como nos metadados, como reconhecimento do apoio prestado e para acompanhar os resultados das suas políticas de financiamento.

O modo de edição permite editar o seguinte campo:

- **Instituição**: pesquisa da instituição financiadora na base de dados [ROR](https://ror.org/). Se a instituição não estiver disponível, [solicite](https://docs.google.com/forms/d/e/1FAIpQLSdJYaMTCwS7muuTa-B_CnAtCSkKzt19lkirAKG4u7umH9Nosg/viewform) ao ROR que a adicione.
