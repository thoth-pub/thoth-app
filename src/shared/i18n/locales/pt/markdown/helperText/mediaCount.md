# Contagem de Média

Esta secção gere a **Contagem de Tabelas**, a **Contagem de Imagens**, a **Contagem de Áudio** e a **Contagem de Vídeo** relativas à obra.

O modo de edição permite editar os seguintes campos:

- **Contagem de Tabelas**: campo numérico inteiro para o número total de tabelas na obra.
- **Contagem de Imagens**: campo numérico inteiro para o número total de imagens na obra.
- **Contagem de Áudio**: campo numérico inteiro para o número total de fragmentos de áudio na obra.
- **Contagem de Vídeo**: campo numérico inteiro para o número total de fragmentos de vídeo na obra.
