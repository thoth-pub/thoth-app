# Tipo de Recurso

Esta secção gere o **Tipo de Recurso** relativo a um Recurso Adicional relacionado com a obra.

O modo de edição permite selecionar a partir da lista suspensa. Estão disponíveis os seguintes tipos:

- Artigo
- Áudio
- Blogue
- Livro
- Conjunto de Dados
- Documento
- Imagem
- Mapa
- Outro
- Fonte
- Folha de Cálculo
- Vídeo
- Sítio Web
