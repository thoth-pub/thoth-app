# Tipo de Colaborador

Esta secção gere o **Tipo de Colaborador** de um Colaborador.

O modo de edição permite selecionar o **Tipo de Colaborador** a partir da lista suspensa. Estão disponíveis as seguintes opções:

- Posfácio de
- Autor
- Contribuições de
- Editor
- Apresentação de
- Ilustrador
- Indexador
- Introdução de
- Editor Musical
- Fotógrafo
- Prefácio de
- Investigação de
- Software de
- Tradutor

Para assinalar o colaborador principal, clique na caixa de seleção **Colaborador Principal**.
