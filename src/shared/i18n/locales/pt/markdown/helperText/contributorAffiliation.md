# Afiliação

Esta secção gere a **Afiliação** de um Colaborador.

- **Instituição**: pesquisa da instituição do colaborador na base de dados [ROR](https://ror.org/). Se a instituição não estiver disponível, [solicite](https://docs.google.com/forms/d/e/1FAIpQLSdJYaMTCwS7muuTa-B_CnAtCSkKzt19lkirAKG4u7umH9Nosg/viewform) ao ROR que a adicione.
- **Cargo**: campo de texto para o cargo do Colaborador na Instituição.
