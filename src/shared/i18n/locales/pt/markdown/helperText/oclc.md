# Número OCLC

Esta secção gere o [**Número OCLC**](https://www.oclc.org/bibformats/en/fixedfield/oclc.html). Este identificador persistente é apenas relevante para editoras sediadas nos Estados Unidos.

O modo de edição permite editar o seguinte campo:

- **Número OCLC**: campo de texto para o número OCLC da obra.
