# ORCID

Esta secção gere o **ORCID** de um Colaborador.

O modo de edição permite editar o seguinte campo:

- **ORCID**: campo de texto para o [ORCID](https://orcid.org/) do colaborador. Recomenda-se que os colaboradores criem um ORCID, caso ainda não o tenham feito, uma vez que este permite o controlo de identidade ao longo de toda a cadeia de publicação do livro.
