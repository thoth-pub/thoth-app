# Locais

Esta secção gere os **Locais** de uma Publicação. Estes podem referir-se, por exemplo, a sítios web de lojas online ou distribuidores (para livros impressos) ou repositórios (para livros digitais).

O modo de edição permite editar os seguintes campos:

- **Plataforma**: selecione uma Plataforma a partir da lista suspensa. Estas incluem todas as plataformas para as quais o Thoth dissemina, bem como as plataformas:
  - **Sítio Web da Editora**: o sítio web da editora, caso esta aloje a publicação num servidor próprio.
  - **Thoth (CDN da Editora)**: a Rede de Distribuição de Conteúdo do Thoth, alojada sob o domínio da Editora, disponível para clientes do [Thoth Obelisk](https://thoth.pub/), [Sphinx](https://thoth.pub/) e [Pyramid](https://thoth.pub/).
  - **Outro**: qualquer outra plataforma não listada.
- **URL da Página de Destino**: o URL da Página de Destino da Publicação. Esta página web apresenta geralmente uma apresentação legível da Publicação, como a página do produto na Amazon ou a listagem no JSTOR.
- **URL do Texto Completo**: o URL para o Texto Completo da Publicação. Trata-se de um URL que conduz diretamente ao ficheiro do livro digital na Plataforma especificada. Normalmente, este URL só está disponível em plataformas abertas. Este campo só está disponível para publicações digitais. Em alternativa, os subscritores do [Thoth Obelisk](https://thoth.pub/), [Sphinx](https://thoth.pub/) ou [Pyramid](https://thoth.pub/) podem clicar no ícone de anexo para carregar o ficheiro diretamente para a sua CDN.
- **Canónico**: este campo assinala a versão de referência da Publicação. Para publicações digitais, o local predefinido é **Thoth (CDN da Editora)**, se disponível.
