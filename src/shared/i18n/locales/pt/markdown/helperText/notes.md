# Notas

Esta secção gere a **Nota Geral** e a **Nota Bibliográfica** da obra. Estes campos já não são geralmente utilizados em registos de metadados, com exceção dos registos MARC.

O modo de edição permite editar os seguintes campos:

- **Nota Geral**: campo de texto de uso geral para incluir informação que não tem um campo específico designado. Exemplos de notas gerais: "Edição anterior: 2017"; "Ligações a recursos adicionais estão disponíveis no sítio web da editora"; "Note-se que neste livro as fórmulas matemáticas estão codificadas em MathML."
- **Nota Bibliográfica**: campo de texto para uma nota que indica que a obra contém uma bibliografia ou informação semelhante. Exemplos de notas bibliográficas: "Inclui bibliografia (páginas 289-321) e índice"; "Inclui referências bibliográficas."
