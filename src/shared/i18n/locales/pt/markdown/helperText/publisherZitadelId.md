# ID de Organização no Zitadel

Esta secção gere o **ID de Organização no Zitadel**.

*N.B. Este é um campo de configuração e só deve ser modificado se estiver familiarizado com a configuração de contas de utilizador.*

O modo de edição permite editar o seguinte campo:

- **ID de Organização no Zitadel**: campo de texto para o identificador único da organização no Zitadel associada a esta editora. Este identificador é utilizado para associar os utilizadores e as suas permissões de acesso à editora correta.
