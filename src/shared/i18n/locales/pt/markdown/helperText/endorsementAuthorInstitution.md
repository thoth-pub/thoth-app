# Instituição do Autor

Esta secção gere a **Instituição do Autor** relativa a uma Recomendação atribuída à obra.

O modo de edição permite editar o seguinte campo:

- **Instituição do Autor**: pesquisa da instituição do autor da recomendação na base de dados [ROR](https://ror.org/). Se a instituição não estiver disponível, [solicite](https://docs.google.com/forms/d/e/1FAIpQLSdJYaMTCwS7muuTa-B_CnAtCSkKzt19lkirAKG4u7umH9Nosg/viewform) ao ROR que a adicione.
