# Nome do Autor

Esta secção gere o **Nome do Autor** relativo a uma Recomendação atribuída à obra. Os subscritores do [Thoth Pyramid](https://thoth.pub/) podem apresentar recomendações como parte das páginas dos seus livros.

O modo de edição permite editar o seguinte campo:

- **Nome do Autor**: campo de texto para o nome do autor da recomendação.
