# ISSN

Esta secção gere o **ISSN** de uma série. Um ISSN é um código de 8 dígitos utilizado para identificar recursos contínuos. Um recurso contínuo é um recurso, em qualquer suporte, publicado indefinidamente ao longo do tempo.

O modo de edição permite editar o seguinte campo:

- **ISSN**: campo de texto para o [ISSN](https://portal.issn.org/) da série.
