# Idiomas

Esta secção gere o(s) **Idioma(s)** utilizados na obra.

O modo de edição permite editar os seguintes campos:

- **Idioma**: selecione o idioma utilizado na obra. A lista de idiomas permitidos segue a norma [ISO 639-3](https://iso639-3.sil.org/code_tables/639/data). Recomenda-se a indicação de pelo menos um idioma.
- **Relação Linguística**: selecione a relação do idioma selecionado com a obra. Estão disponíveis as seguintes opções:
  - Original;
  - Traduzido de;
  - Traduzido para.
