# Acessibilidade

Esta secção gere a **Acessibilidade** de uma Publicação. Esta secção está disponível apenas para publicações digitais, com exceção dos audiolivros.

O modo de edição permite editar os seguintes campos:

- **Especificação**: selecione a especificação de Acessibilidade com a qual a publicação está em conformidade:
  - [WCAG 2.1 AA](https://www.w3.org/TR/WCAG21/)
  - [WCAG 2.1 AAA](https://www.w3.org/TR/WCAG21/)
  - [WCAG 2.2 AA](https://www.w3.org/TR/WCAG22/)
  - [WCAG 2.2 AAA](https://www.w3.org/TR/WCAG22/)
  - [PDF/UA-1](https://pdfa.org/resource/iso-14289-pdfua/)
  - [PDF/UA-2](https://pdfa.org/resource/iso-14289-pdfua/)
- **Exceção**: caso a Editora esteja isenta de tornar as suas publicações acessíveis ao abrigo de uma jurisdição específica, selecione o tipo de Exceção a partir da lista suspensa:
  - Encargo Desproporcionado
  - Alteração Fundamental
  - Microempresas
- **URL do Relatório**: URL do relatório de acessibilidade da Publicação.

Consulte o [Copim Compass](https://compass.copim.pub/books/09-open-book-accessibility) para um recurso abrangente sobre Acessibilidade.
