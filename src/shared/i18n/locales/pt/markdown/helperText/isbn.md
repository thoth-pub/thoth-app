# ISBN

Esta secção gere o **ISBN** de uma Publicação.

O modo de edição permite editar o seguinte campo:

- **ISBN**: campo de texto para o ISBN-13 da publicação. Os números ISBN podem geralmente ser obtidos junto de uma [agência nacional de ISBN](https://www.isbn-international.org/agencies). Recomenda-se que cada Publicação tenha um ISBN único.
