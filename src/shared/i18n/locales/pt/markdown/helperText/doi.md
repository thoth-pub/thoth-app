# DOI

Esta secção gere o **DOI** (recomendado) e a **Página de Destino** (recomendada).

O modo de edição permite editar os seguintes campos:

- **DOI**: campo de texto para o Identificador de Objeto Digital (DOI) da obra (sem o prefixo `https://doi.org/`). Os DOIs são atribuídos por agências de registo como a [Crossref](https://www.crossref.org/). O registo automático de DOIs na Crossref pode ser configurado através do [Thoth Obelisk](https://thoth.pub/).
- **URL da Página de Destino**: campo de texto para o URL da página de destino da obra. Deve ser um URL válido onde os utilizadores possam aceder à obra, por exemplo, a página do livro no sítio web de uma editora. Este URL *não* pode ser um DOI.
