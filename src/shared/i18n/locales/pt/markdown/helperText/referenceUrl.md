# URL

Esta secção gere o **URL** relativo a uma Referência contida na obra.

O modo de edição permite editar o seguinte campo:

- **URL**: campo de texto para o URL que liga à Referência. Pode ser o URL da própria referência (como um ficheiro PDF alojado) ou a página de destino da referência no sítio web da editora ou no sítio web de um repositório como o JSTOR ou o Project MUSE. Este campo não pode conter um DOI.
