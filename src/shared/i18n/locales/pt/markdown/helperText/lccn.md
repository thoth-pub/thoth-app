# LCCN

Esta secção gere o [Número de Controlo da Biblioteca do Congresso](https://www.loc.gov/programs/preassigned-control-number/about-this-program/) (**LCCN**). Este identificador persistente é apenas relevante para editoras sediadas nos Estados Unidos.

O modo de edição permite editar o seguinte campo:

- **LCCN**: campo de texto para o LCCN da obra.
