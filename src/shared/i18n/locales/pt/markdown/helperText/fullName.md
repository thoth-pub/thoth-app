# Nome Completo

Esta secção gere o **Nome Completo** de um Colaborador.

Pode criar um novo colaborador ou pesquisar um Colaborador na base de dados do Thoth. Para fins de desambiguação, o [ORCID](https://orcid.org/) do Colaborador é apresentado quando disponível. Recomenda-se verificar sempre o nome de um colaborador primeiro, uma vez que outro utilizador do Thoth pode já ter criado o seu registo.

O modo de edição permite editar os seguintes campos:

- **Nome Completo**, especificado como:
  - **Nome Próprio**: campo de texto para o nome próprio do colaborador, geralmente o nome atribuído num momento significativo da sua vida, como o nascimento, o batismo, a maioridade ou a obtenção de um estatuto específico na sociedade. Os colaboradores podem optar por abreviar o nome próprio a uma inicial.
  - **Apelido**: campo de texto para o Apelido do Colaborador, geralmente transmitido ao Colaborador pelo seu contexto social, seja pelos pais, pela família (adotiva), pelo clã ou por outro grupo. O Apelido é utilizado para ordenar o nome alfabeticamente.
  - **Nome Completo**: campo de texto para o nome completo do colaborador, constituído pela ordenação do **Nome Próprio** e do **Apelido**. A ordem pode variar consoante as preferências pessoais ou culturais.

*N.B.: a alteração de qualquer um dos campos acima só modifica o nome do colaborador para esta obra em particular. O registo subjacente do colaborador não é alterado, uma vez que pode estar em uso noutros registos (de outras editoras).*
