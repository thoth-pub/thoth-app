# URL do Vídeo

Esta secção gere o **URL do Vídeo** de um Vídeo em Destaque relativo à obra.

O modo de edição permite editar o seguinte campo:

- **URL do Vídeo**: campo de texto para o URL do vídeo. Em alternativa, os subscritores do [Thoth Pyramid](https://thoth.pub/) podem clicar no ícone de anexo para carregar o ficheiro diretamente para a sua CDN.
