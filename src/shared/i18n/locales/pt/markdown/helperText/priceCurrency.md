# Preço

Esta secção gere o **Preço** de uma Publicação.

O modo de edição permite editar o seguinte campo:

- **Preço**: campo de entrada de número de vírgula flutuante (com duas casas decimais) para o preço e seleção da moeda a partir da lista suspensa, seguindo a nomenclatura e abreviaturas do padrão [ISO 4217](https://en.wikipedia.org/wiki/ISO_4217).

Podem ser introduzidos preços adicionais noutras moedas clicando em **Adicionar Novo Preço**.
