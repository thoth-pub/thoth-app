# Zitadel Organisation ID

This section manages the **Zitadel Organisation ID**.

*N.B. This is a configuration field and should only be modified if you are familiar with user account setup.*

Edit mode allows the editing of the following field:

- **Zitadel Organisation ID**: text input for the unique identifier of the organisation in Zitadel that is linked to this publisher. This is used to associate users and their access permissions with the correct publisher.
