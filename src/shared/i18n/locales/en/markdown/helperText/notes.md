# Notes

This section manages the **General Note** and **Biliography Note** to the work. These fields are generally no longer used in metadata records, with the exception of MARC records.

Edit mode allows the editing of the following fields:

- **General Note**: text input for a general-purpose field used to include information that does not have a specific designated field. Examples of general notes: "Previous edition: 2017"; "Links to additional resources are available from the publisher's website"; "Please note that in this book the mathematical formulas are encoded in MathML."
- **Bibliography Note**: text input for a note that indicates that the work contains a bibliography or other similar information. Example of a bibliography note: "Includes bibliography (pages 289-321) and index"; "Includes bibliographical references."
