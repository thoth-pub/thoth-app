# Funding

This section manages **Funding** sources of the Work. Funders often require that this information is included both in the Work and the metadata as acknowledgment of the support but also to track the outcomes of their funding policies.

Edit mode allows the editing of the following field:

- **Institution**: lookup for the funding institution in the [ROR](https://ror.org/) database. If the institution is not available, [request](https://docs.google.com/forms/d/e/1FAIpQLSdJYaMTCwS7muuTa-B_CnAtCSkKzt19lkirAKG4u7umH9Nosg/viewform) ROR to add it.
