## Abstract

This section manages **Abstract** and **Short Abstract**.

Edit mode allows the editing of the following fields:

- **Abstract**: text input for the abstract of the work. Where a work has only one abstract, it should be entered here, and short abstract may be left blank.
- **Short Abstract**: text input for the short abstract. Not used in metadata exports, but may be used for a short abstract that is displayed on, e.g., a summary/snippet view on a website.

## JATS XML

Both **Abstract** and **Short Abstract** allow formatting in JATS XML for boldface, italics, strikethrough, underline, paragraphs, lists, and hyperlinks.

- [boldface](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/bold.html): `<bold>text</bold>`
- [italics](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/italic.html): `<italic>text</italic>`
- [strikethrough](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/strike.html): `<strike>text</strike>`
- [underline](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/underline.html): `<underline>text</underline>`
- [paragraphs](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/p.html): `<p>text</p>`
- [ordered lists](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/list.html): `<ol>text</ol>`
- [unordered lists](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/list.html): `<ul>text</ul>`
- [hyperlinks](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/ext-link.html): `<ext-link ext-link-type="uri" xlink:href="#">text</ext-link>`

## Multilingual Options

The **Language** dropdown allows setting the language of the **Abstract** and **Short Abstract**. The list of permitted languages and language variants encompasses a two-letter [ISO 639-1](https://www.loc.gov/standards/iso639-2/php/code_list.php) language code followed by a two-letter [ISO 3166-1 alpha-2](https://en.wikipedia.org/wiki/List_of_ISO_3166_country_codes) country code.

The **Add New Translation** button allows the addition of a translation of the **Abstract** and **Short Abstract** in another Language.
