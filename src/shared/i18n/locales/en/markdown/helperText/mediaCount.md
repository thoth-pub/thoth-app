# Media Count

This section manages the **Table Count**, **Image Count**, **Audio Count**, and **Video Count** pertaining to the work.

Edit mode allows the editing of the following fields:

- **Table Count**: integer input for the total number of tables in the work.
- **Image Count**: integer input for the total number of images in the work.
- **Audio Count**: integer input for the total number of audio fragments in the work.
- **Video Count**: integer input for the total number of video fragments in the work.
