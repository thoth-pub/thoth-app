# Locations

This section manages the **Locations** of a Publication. These may refer to for example websites of online shops or distributors (for print books) or repositories (for digital books).

Edit mode allows the editing of the following fields:

- **Platform**: select a Platform from the dropdown list. These include all the platforms that Thoth disseminates to, as well as the platforms:
  - **Publisher Website**: The website of the publisher, if they host the publication themselves on a proprietary server.
  - **Thoth (Publisher CDN)**: The Content Distribution Network of Thoth hosted under the Publisher's domain, available to customers of [Thoth Obelisk](https://thoth.pub/), [Sphinx](https://thoth.pub/), and [Pyramid](https://thoth.pub/),
  - **Other**: Any other platform not listed.
- **Landing Page URL**: the URL of Landing Page of the Publication. This web page usually provides a human-readable presentation of the Publication, such as the product page on Amazon or JSTOR listing.
- **Full Text URL**: the URL to the Full Text of the Publication. This is a URL leading directly to the digital book file on the specified Platform. Usually, this URL is only available on open platforms. This field is only available for digital publications. Alternatively, subscribers to [Thoth Obelisk](https://thoth.pub/), [Sphinx](https://thoth.pub/), or [Pyramid](https://thoth.pub/) may click the attachment icon to upload their file directly to their CDN.
- **Canonical**: This marks the version of record of the Publication. For digital publications this is the **Thoth (Publisher CDN)** location by default, if available.
