# Series

This section manages the **Series** name and the Volume **Number** of the work in that particular series.

Edit mode allows the editing of the following fields:

- **Series**: select the name of series to which the work belongs from the dropdown list.
- **Number**: integer input for the ordinal of the work in the series, determining the order in which works in the same series are listed. Note that if the series has explicit "issue numbers", the ordinal used here does not need to correspond to those.
