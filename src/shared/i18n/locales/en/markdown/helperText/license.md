# License

This section manages the **License** (mandatory) and the **Copyright Holder** (mandatory). The **License** will already have been provided during the setup process.

Edit mode allows the editing of the following fields:

- **License**: select the license of the work from the dropdown list. Allowed are current [Creative Commons (CC)](https://creativecommons.org/share-your-work/) licenses, legacy CC licenses, as well as Public Domain and non-OA licenses such as All Rights Reserved.
- **Copyright Holder**: text input for the copyright holder of the work.
