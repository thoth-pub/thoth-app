# Contributor Type

This section manages the **Contributor Type** of a Contributor.

Edit mode allows the selection of the **Contributor Type** from the dropdown list. The following options are available:

- Afterword by
- Author
- Contributions by
- Editor
- Foreword by
- Illustrator
- Indexer
- Introduction by
- Music Editor
- Photographer
- Preface by
- Research by
- Software by
- Translator

To mark lead of main contributors, click the checkbox **Lead Contributor** checkbox.
