# Author Institution

This section manages the **Author Institution** pertaining to an Endorsement given to the work.

Edit mode allows the editing of the following field:

- **Author Institution**: lookup for the endorsement author's institution in the [ROR](https://ror.org/) database. If the institution is not available, [request](https://docs.google.com/forms/d/e/1FAIpQLSdJYaMTCwS7muuTa-B_CnAtCSkKzt19lkirAKG4u7umH9Nosg/viewform) ROR to add it.
