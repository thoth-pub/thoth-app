# Accessibility

This section manages the **Accessibility** of a Publication. This section is only available for digital publications, with the exception of Audiobooks.

Edit mode allows the editing of the following fields:

- **Specification**: select the Accessibility specification with which the publication is compliant:
  - [WCAG 2.1 AA](https://www.w3.org/TR/WCAG21/)
  - [WCAG 2.1 AAA](https://www.w3.org/TR/WCAG21/)
  - [WCAG 2.2 AA](https://www.w3.org/TR/WCAG22/)
  - [WCAG 2.2 AAA](https://www.w3.org/TR/WCAG22/)
  - [PDF/UA-1](https://pdfa.org/resource/iso-14289-pdfua/)
  - [PDF/UA-2](https://pdfa.org/resource/iso-14289-pdfua/)
- **Exception**: if the Publisher is exempt from making their publications accessible under a specific jurisdiction, select the type of Exception from the dropdown list:
  - Disproportionate Burden
  - Fundamental Alteration
  - Micro Enterprises
- **Report URL**: URL of the accessibility report of the Publication.

See the [Copim Compass](https://compass.copim.pub/books/09-open-book-accessibility) for an extensive resource on Accessibility.
