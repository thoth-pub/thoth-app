# DOI

This section manages the **DOI** (recommended) and **Landing Page** (recommended).

Edit mode allows the editing of the following fields:

- **DOI**: text input for the Digital Object Identifier (DOI) of the work (without the prefix `https://doi.org/`). DOIs are assigned via registration agencies such as [Crossref](https://www.crossref.org/). You can automate DOI registration via Crossref through [Thoth Obelisk](https://thoth.pub/).
- **Landing Page URL**: text input for the landing page URL of the work. This should be a valid URL where users can access the work, e.g., the book's landing page on a publisher's website. This URL may *not* be a DOI.
