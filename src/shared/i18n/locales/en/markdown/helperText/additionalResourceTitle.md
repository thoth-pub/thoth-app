# Resource Title

This section manages the **Resource Title** pertaining to an Additional Resource related to the work. Additional Resources may be any additional multimedia materials that are not directly Marketing-related, book websites, translations, datasets, audio files, and so on.

Additional resources can be shown on websites featuring a catalog powered by Thoth, as available via [Thoth Pyramid](https://thoth.pub/).

Edit mode allows the editing of the following field:

- **Resource Title**: text input for the Title of the Additional Resource.
