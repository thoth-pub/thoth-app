# URL

This section manages the **URL** pertaining to a Reference contained in the work.

Edit mode allows the editing of the following field:

- **URL**: text input for the URL linking to the Reference. This may be the URL of the reference itself (such as a hosted PDF file) or the landing page of the reference on the publisher’s website or the website of a repository such as JSTOR or Project MUSE. This may not be a DOI.
