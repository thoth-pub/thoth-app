# Page Count

This section manages the **Total Page Count** as well as the **Frontmatter Count** and **Backmatter Count**.

Edit mode allows the editing of the following fields:

- **Total Page Count**: integer input for the total number of pages in the work (recommended).
- **Frontmatter Count**: integer input for the total number of frontmatter pages in the work. This usually encompasses the frontmatter as well as any sections numbered in Roman numerals.
- **Backmatter Count**: integer input for the total number of backmatter pages in the work. This usually includes appendices and indexes.
