# Full Name

This section manages the **Full Name** of a Contributor.

You can either create a new contributor or look up a Contributor in the Thoth database. For disambiguation purposes the Contributor’s [ORCID](https://orcid.org/) is displayed when available. It is advised to always look up a contributor's name first, since another Thoth user may have already created their record.

Edit mode allows the editing of the following fields:

- **Full Name**, further specified as:
  - **Given Name**: text input for the given name of the contributor, usually the name given at a significant event in the contributor’s life, such as birth, baptism, coming of age, or achieving a specific status in society. Contributors may choose to abbreviate their given name to an initial.
  - **Family Name**: text input for the Family Name of the Contributor, usually handed down to the Contributor by their social context, be that parent, (adoptive) family, tribe, or other grouping. The Family Name is used for collating the name alphabetically.
  - **Full Name**: text input for the full name of the contributor, consisting of an ordering of **Given Name** and **Family Name**. Ordering may vary based on personal or cultural preferences.

*N.B.: changing any of the above fields only changes the contributor’s name for this particular work. The underlying contributor record doesn’t change since it may be in use in (another publisher’s) records.*
