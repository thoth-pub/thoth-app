# Subjects

This section manages the **Subject(s)** describing the work.

The following subject types are supported:

- **BIC**: BIC subject codes have been phased out in favor Thema. These only appear in legacy records and should not be added to new ones.
- [**BISAC**](bisg.org/page/BISACEdition): a subject classification scheme maintained by the Book Industry Study Group, which maintains the subject code list.
- **Custom**: text labels linked to a publisher-specific subject classification
- **Keyword**: free text labels for publisher-specified keywords
LCC: a subject classification scheme maintained by the Library of Congress, which maintains the subject code list.
- [**Thema**](https://ns.editeur.org/thema/en): an open, multilingual subject classification scheme maintained by EDItEUR, which maintains the subject code list and documentation on its usage. It is recommended to use at least two Thema codes to describe a publication.
