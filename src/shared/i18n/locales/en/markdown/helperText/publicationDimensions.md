# Dimensions

This section manages the **Dimensions** of a Publication. This section is only available for Hardback and Paperback publications.

Edit mode allows the editing of the following fields:

- **Width**: floating point number input for the **Width** of the publication in mm/in.
- **Height**: floating point number input for the **Height** of the publication in mm/in.
- **Depth**: floating point number input for the **Depth** of the publication in mm/in.
- **Weight**: floating point number input for the **Weight** of the publication in g/oz.

Dimensions may be entered in either Metric or Imperial units, and are automatically converted from one to the other. Units may be linked and delinked by clicking the chain icon.
