# Affiliation

This section manages the **Affiliation** of a Contributor.

- **Institution**: lookup for the contributor's institution in the [ROR](https://ror.org/) database. If the institution is not available, [request](https://docs.google.com/forms/d/e/1FAIpQLSdJYaMTCwS7muuTa-B_CnAtCSkKzt19lkirAKG4u7umH9Nosg/viewform) ROR to add it.
- **Position**: text input for the position of the Contributor at the Institution.
