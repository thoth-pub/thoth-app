# Work Type

This section manages **Work Type** (mandatory). The **Work Type** will already have been provided during the setup process.

The following work types are available:

- **Edited Book**: a collection of shorter works by different authors on an overarching theme.
- **Journal Issue**: a single publication within a series of collections of related articles.
- **Monograph**: a long-form work on a single theme, by a small number of authors.
- **Textbook**: a work used for educational purposes.
