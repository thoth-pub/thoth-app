# Languages

This section manages the **Language(s)** used in the work.

Edit mode allows the editing of the following fields:

- **Language**: select the language used in the work. The list of permitted languages follows [ISO 639-3](https://iso639-3.sil.org/code_tables/639/data). At least one language is recommended.
- **Language Relation**: select the relation of the selected language to the work. The following options are available:
  - Original;
  - Translated From;
  - Translated To.
