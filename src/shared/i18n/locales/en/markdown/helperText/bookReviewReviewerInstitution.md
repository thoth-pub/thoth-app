# Reviewer Institution

This section manages the **Reviewer Institution** pertaining to a Review of the work.

Edit mode allows the editing of the following field:

- **Author Institution**: lookup for the review author's institution in the [ROR](https://ror.org/) database. If the institution is not available, [request](https://docs.google.com/forms/d/e/1FAIpQLSdJYaMTCwS7muuTa-B_CnAtCSkKzt19lkirAKG4u7umH9Nosg/viewform) ROR to add it.
