# Publication Type

This section manages **Publication Type** of a Publication. Publications are separate instances of a single work of a specific material type.

Edit mode allows the selection of the **Publication Type** from the dropdown list. The following options are available:

- **AZW3**: digital book in AZW3 format. AZW3 is a proprietary Amazon Kindle ebook file format, supporting a subset of HTML and CSS features, acting like a container for a MOBI file. Support and development of AZW3 has ended.
- **DOCX**: digital book in DOCX format. DOCX is a zipped, XML-based file format developed by Microsoft for representing word processing documents.
- **EPUB**: digital book in EPUB format. EPUB is a zipped, XML-based ebook file format published by the International Digital Publishing Forum. It is supported by a variety of e-readers.
- **FictionBook**: digital book in FictionBook format. FictionBook an open XML-based ebook format.
- **Hardback**: print book with a hardbound cover.
- **HTML**: digital book in HTML format. Hypertext Markup Language (HTML) is the standard markup language for human-readable documents designed to be displayed in a web browser.
- **MOBI**: digital book in MOBI format. MOBI is an ebook file format developed by Mobipocket, later used by Amazon as the basis for AZW3. Support and development of MOBI has ended.
- **MP3**: audiobook in MP3 format. MPEG-1/MPEG-2 Audio Layer III (MP3) is an open lossy audio coding format developed mainly by the Fraunhofer Society in Germany.
- **Paperback**: print book with a paperbound cover
- **PDF**: digital book in PDF format. PDF is a human-readable file format developed by Adobe. It is based on Postscript and encodes the appearance of information on a printed page.
- **WAV**: audiobook in WAV format. Waveform Audio File Format (WAV) is an audio file format developed by IBM and Microsoft.
- **XML**: digital book in XML format. Extendable Markup Language (XML) is a markup language designed for both human-readable and machine-readable documents.
